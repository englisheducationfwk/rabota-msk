# Работа MSK — вакансии с Авито

Свежие вакансии (горничная, уборщица, домработница, клининг — **Москва**)
сами приезжают на страницу-приложение: компьютер раз в 15 минут забирает
их с Авито, отсеивает мусор («курьер» под словом «горничная») и
публикует. Открывается со смартфона как обычное приложение.

```
Авито (Москва, «Работа»)
   ↓  каждые 15 минут            ← сервер живёт в трее (иконка 💼)
Ваш ПК: сбор → мозг → база
   ↓
GitHub: ветка data (один обновляемый коммит)
   ↓
GitHub Pages — страница «Работа MSK» (docs/)
   ↓
iPhone: иконка на экране Домой, карточки, «Новых: N»
   ↓ (опция)
Telegram: дайджест новых вакансий
```

## Что умеет

- **Москва и только Москва**, свежие сверху; на каждой карточке видно,
  **когда объявление опубликовано на Авито** («опубликовано сегодня
  в 17:02 · 2 часа назад»).
- **Отсев ложных «горничных»**: курьер/доставка/водитель/грузчик,
  резюме соискателей, «уборка» вскользь — вон; у каждой вакансии
  видно, почему она прошла или отсеяна.
- **Оценка «выгоды» 0–100** с расшифровкой («Почему такая оценка»):
  оплата, без оформления — плюс; рейтинг с отзывами, свежесть —
  плюс; агентство, мутные заголовки — минус.
- **Рейтинг работодателя** (звёзды + число отзывов) прямо в карточке.
- **«Новых: N»** — сколько появилось с прошлого визита.
- **Кнопки на карточке**: избранное, заметка, «не подходит» (убрать
  одну) и **«Заблокировать»** — с подтверждением, прячет работодателя
  целиком; вернуть всех можно чипом «Разблокировать» сверху.
- **Страница**: крупные шрифты, тёмная и светлая темы, фильтры
  (без оформления, оплата от…), сортировки (выгода / зарплата /
  свежие / рейтинг), поиск, кнопка «наверх» и **память прокрутки** —
  возвращаешься туда же, где остановилась.
- Избранное, скрытые, блокировки и заметки хранятся на телефоне,
  никуда не отправляются.
- **Telegram (опция)**: вставили токен бота — новые подходящие вакансии
  приходят дайджестом. Пусто — тишина.

## Устройство

| Файл | Что это |
|---|---|
| `panel/panel.py` | окно + жизнь в трее: «Включить/Выключить сервер», настройки, журнал |
| `collector/collect.py` | цикл сбора: Авито → мозг → база → JSON → GitHub |
| `collector/netguard.py` | прямой РУ-канал (bind к Wi-Fi, мимо туннеля Happ) + страж страны IP |
| `collector/avito.py` | поиск и детали вакансий живым браузером (куки после входа) |
| `collector/brain.py` | правила: отсев ложных «горничных» + оценка «выгоды» |
| `collector/store.py` | база SQLite + срез `data/vacancies.json` для страницы |
| `collector/publish.py` | публикация данных на GitHub (ветка `data`, один коммит) |
| `collector/notify.py` | Telegram (опция) |
| `docs/` | страница (GitHub Pages): index.html + app.js + app.css |
| `_tools/вход_в_авито.py` | разовый вход в Авито: живой браузер, вы проходите проверку |
| `_tools/proxy_bridge.py` | локальный мостик: браузер ходит напрямую, с РУ-IP |
| `_tools/selftest.py` | офлайн-проверки мозга/зарплат/базы (без интернета) |
| `_tools/e2e.py` | страница на локальном сервере + скриншоты `_shots/` |

## Запуск и жизнь в фоне

1. Ярлык **«Работа MSK»** на рабочем столе → окно панели.
2. Первый раз: **🔑 Войти в Авито** — откроется браузер, нажмите
   «Продолжить» и пройдите проверку; окно закроется само.
   Профиль с куками сохранится, дальше сбор ходит молча.
3. **▶ Включить сервер** — сбор сразу, дальше по режиму (ниже).

Дальше серверу можно не мешать:

- **Крестик** на окне — уйти в трей (иконка 💼 у часов). Сбор продолжает
  работать; если процесс почему-то упадёт, панель поднимет его сама.
- **Автозапуск** (галочка в ⚙️ Настройках) уже включён: после
  перезагрузки ПК панель стартует вместе с Windows сразу в трее,
  и сбор запускается автоматически. Снять галочку = выключить.
- Полностью остановить всё: трей → правая кнопка → **«Выйти совсем»**
  (или кнопка в окне).

## Два режима сбора (переключаются в трее)

| Режим | Что делает |
|---|---|
| **🕐 2 раза в день** (по умолчанию) | Сбор в 10:00 и 19:00 — самые «сочные» часы: утром выходят свежие объявления, вечером люди публикуют после работы |
| **⚡ Каждые 15 минут** | Те же 10:00 и 19:00, **плюс** каждые 15 минут с 8:00 до 24:00 (ночью спим — объявлений почти нет) |

Переключение: правой кнопкой по иконке 💼 в трее → «Режим: …»,
или кнопками в окне панели. Сбор подхватывает смену в течение
30 секунд, перезапускать ничего не надо.

## Брандмауэр

Python уже прописан в брандмауэре Windows (правила «Rabota MSK:
python.exe / pythonw.exe», вход и выход, все профили). Если у вас стоит
**Fort Firewall**: при первом сборе он может спросить про `python.exe`
и `pythonw.exe` — разрешите им доступ («always allow»).

## Если Авито показал «Доступ ограничен»

Это проверка IP (Авито защищается от роботов). Нажмите «🔑 Войти в
Авито», в открывшемся окне — «Продолжить» и проверку, затем снова
«Включить». Нужно редко: сессия живёт неделями, а мягкие проверки
безопасности сбор проскакивает сам.

**Тонкости, из-за которых всё и работает:**

- Сбор идёт **мимо туннеля Happ**: трафик привязывается к Wi-Fi-адресу
  (`bind`), поэтому Авито видит российский IP. Если интернет выключен
  или Wi-Fi отвалился, панель честно скажет «Трафик идёт через туннель»
  и сбор не начнётся — так и задумано.
- Браузер при сборе запускается **видимым** (свёрнутое окно): Авито
  отличает headless-браузеры и режет их.

## GitHub Pages

Страница живёт в папке `docs/` → Settings → Pages → Deploy from branch:
`main` / `/docs`. Данные для пользователя — в ветке `data` (обновляется одним
amend-коммитом, история чистая).

## Проверки

```
python _tools/selftest.py     # мозг, зарплаты, база — офлайн
python _tools/e2e.py --demo   # страница + скриншоты в _shots/
```

## Нагрузка на Авито

Проект ходит вежливо: 1 поток, паузы 3–6 секунд, детали — только для
новых вакансий (не больше 12 за цикл), период — 15 минут. Это личный
инструмент для поиска работы, не парсер-выгрузка.
